# METTLE — PROJECT CONTEXT FOR COPILOT

## What this project is
Mettle is a consulting-led firm.
We solve complex business problems through clarity, systems thinking, and execution.

This is NOT:
- an agency website
- a service-selling site
- a tech showcase

Technology is a tool, not the product.

## Canonical files (NON-NEGOTIABLE)
- masterPlan.md → narrative, philosophy, content structure
- prompts.md → execution instructions
- ARCHITECTURE.md → architectural and system rules

If anything conflicts:
masterPlan.md > ARCHITECTURE.md > prompts.md

## Tone & philosophy
- Calm
- Precise
- Consulting-grade
- No hype
- No buzzwords
- No sales language

## How work should be described
- Focus on the REAL problem
- Show the insight that unlocked clarity
- Explain the system or approach
- Show outcomes without exaggeration

Never:
- list tools for the sake of it
- sound like a case-study marketing page
- invent metrics or results

If unsure → stop and ask.
